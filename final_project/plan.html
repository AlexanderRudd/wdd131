Overview

Purpose

The purpose of the site is to host a small Yahtzee-based dice game. It will allow the user to roll dice and calculate their hand type. The audience would be anyone who wants to play the game.

Dynamic elements

The dynamic elements will include the dice, the results, and the hand-types. JavaScript will be used to keep track of all the roll information.
